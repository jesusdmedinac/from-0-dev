## 🎯 Fase 2: Introducción al Tema y Fundamentos Teóricos

Analicemos la estructura del sistema de archivos y el catálogo universal de comandos.

---

{/* Tiempo sugerido: 15 min */}
### 1. El Árbol de Directorios y Tipos de Rutas

Todas las carpetas y archivos de una computadora forman un gran árbol invertido:

```
/ (Directorio Raíz del Disco)
├── Users / home (Carpetas de usuarios)
│   └── tu_usuario (Tu carpeta personal: se representa con el símbolo "~")
│       ├── Documentos
│       ├── Descargas
│       └── proyectos
│           └── shorturl
│               ├── server.js
│               └── public
│                   └── index.html
```

#### Rutas Absolutas vs Rutas Relativas:
* **Ruta Absoluta:** Describe el camino completo desde la raíz `/` del disco (ej. `/Users/joul/proyectos/shorturl`). No importa dónde estés parado, siempre llega al mismo lugar.
* **Ruta Relativa:** Describe el camino a partir de **donde estás parado ahora mismo**:
  * `.` (Un punto): Representa el directorio actual.
  * `..` (Dos puntos): Representa la carpeta superior (subir un nivel).

---

{/* Tiempo sugerido: 15 min */}
### 2. El Catálogo Universal de Comandos (POSIX / Unix)

Estos comandos funcionan exactamente igual en macOS, Linux y en la terminal Git Bash / WSL de Windows:

| Comando | Significado | ¿Para qué sirve? |
| :--- | :--- | :--- |
| **`pwd`** | *Print Working Directory* | Muestra la ruta completa de la carpeta en la que estás parado. |
| **`ls`** | *List* | Lista los archivos y carpetas del directorio actual (`ls -la` muestra detalles y ocultos). |
| **`cd`** | *Change Directory* | Cambia de carpeta (ej. `cd proyectos`, `cd ..`, `cd ~`). |
| **`mkdir`** | *Make Directory* | Crea una carpeta nueva (ej. `mkdir mi-carpeta`). |
| **`touch`** | *Touch* | Crea un archivo vacío (ej. `touch index.html`). |
| **`cp`** | *Copy* | Copia archivos o carpetas (`cp archivo.txt copia.txt`). |
| **`mv`** | *Move* | Mueve o renombra un archivo (`mv viejo.txt nuevo.txt`). |
| **`rm`** | *Remove* | Elimina archivos (`rm archivo.txt`). |
| **`cat`** | *Concatenate* | Muestra el contenido completo de un archivo en pantalla. |
| **`grep`** | *Global Regular Expression Print* | Busca una palabra específica dentro de archivos. |
| **`clear`** | *Clear Screen* | Limpia la pantalla de la terminal (`Ctrl + L`). |

{/* Tiempo sugerido: 15 min */}
### 3. El Superpoder de la Tecla `Tab` (Autocompletado)

Los programadores profesionales no escriben nombres de carpetas largos letra por letra. Escriben las primeras dos letras y presionan la tecla **`Tab`**:
* Si escribes `cd pro` y presionas `Tab`, la terminal autocompleta instantáneamente `cd proyectos/`.
* Si presionas la **flecha hacia arriba (`↑`)**, la terminal te muestra el historial de comandos anteriores para no tener que escribirlos de nuevo.

### 🔍 Experimento en Vivo: Tu Primer Vuelo en la Terminal

Vamos a abrir la terminal y realizar un recorrido guiado:

1. **Abre tu Terminal (Terminal en macOS/Linux, Git Bash o PowerShell en Windows).**
2. **Pregúntale a la máquina dónde estás:**
   ```bash
   pwd
   ```
3. **Mira qué hay a tu alrededor:**
   ```bash
   ls -la
   ```
4. **Viaja a tu carpeta personal:**
   ```bash
   cd ~
   pwd
   ```

**Objetivo:** Moverse entre niveles de carpetas sin usar el ratón.

Ejecuta en tu terminal:

```bash
# 1. Viajamos a nuestra carpeta personal

# 2. Creamos una carpeta temporal de experimentos y entramos en ella
mkdir laboratorio-terminal
cd laboratorio-terminal

# 3. Verificamos dónde estamos parados
pwd

# 4. Creamos una subcarpeta y entramos
mkdir nivel-1
cd nivel-1

# 5. Subimos un nivel hacia atrás
cd ..

# 6. Verificamos que volvimos a laboratorio-terminal
pwd
```

### 🧩 Reto 2: Creación de Estructuras en un Solo Comando (`mkdir -p` y `touch`)

**Objetivo:** Crear una arquitectura de proyecto web completa en segundos.

```bash
# Estando dentro de laboratorio-terminal:
# Creamos múltiples carpetas anidadas con el parámetro -p (parents)
mkdir -p mi-app-web/public/css mi-app-web/public/js mi-app-web/src/data

# Entramos al proyecto
cd mi-app-web

# Creamos los archivos base con touch
touch public/index.html public/css/styles.css public/js/app.js src/server.js README.md

# Listamos recursivamente para ver la estructura completa
ls -R
```

{/* Tiempo sugerido: 25 min */}
### 🧩 Reto 3: Escribir, Leer y Filtrar Archivos (`echo`, `cat` y `grep`)

**Objetivo:** Manipular contenido de texto y buscar errores directamente desde la línea de comandos.

```bash
# 1. Escribimos texto dentro de un archivo de logs usando redirección con >
echo "2026-08-18 10:00:00 [INFO] Servidor ShortURL iniciado correctamente" > logs.txt
echo "2026-08-18 10:05:12 [INFO] Petición GET /mdn recibida con éxito" >> logs.txt
echo "2026-08-18 10:12:44 [ERROR] Base de datos no respondió a tiempo" >> logs.txt
echo "2026-08-18 10:15:00 [INFO] Enlace corto generado con éxito: a8B9x" >> logs.txt
echo "2026-08-18 10:20:10 [ERROR] Formato de URL inválido en POST /api/acortar" >> logs.txt

# 2. Leemos todo el archivo en la pantalla con cat
cat logs.txt

# 3. Filtramos ÚNICAMENTE las líneas que contienen la palabra ERROR con grep
grep "ERROR" logs.txt
```

### 🧩 Reto 4: Ejecución de Scripts de Node.js con Parámetros CLI

**Objetivo:** Crear un script en JavaScript que lea argumentos pasados desde la terminal mediante `process.argv`.

Crea un archivo llamado `saludo-cli.js`:

```javascript title="saludo-cli.js"
// process.argv contiene los argumentos pasados en la terminal
const argumentos = process.argv.slice(2);

const nombre = argumentos[0] || "Desarrollador";
const rol = argumentos[1] || "Estudiante";

console.log("=========================================");
console.log(`👋 ¡Hola, ${nombre}!`);
console.log(`💼 Tu rol en el proyecto es: ${rol}`);
console.log(`📅 Fecha de ejecución: ${new Date().toLocaleDateString()}`);
console.log("=========================================");
```

Pruébalo ejecutando en tu terminal:

```bash
node saludo-cli.js Joul Ingeniero
node saludo-cli.js Maria Diseñadora
```

## 🗣️ Fase 4: Exposición de Resultados, Debate y Debugging

Compartimos terminales, revisamos los comandos ejecutados y aprendemos a evitar errores críticos.

### 🐞 Trampas Clásicas y Precauciones de Seguridad en la Terminal

#### 1. ¡Cuidado extremo con `rm -rf`!
* **El peligro:** En la interfaz gráfica, cuando borras un archivo se va a la *Papelera de Reciclaje* y puedes recuperarlo. En la terminal, **`rm` elimina los archivos de forma permanente e irreversible sin confirmación**.
* **Regla de oro:** Nunca ejecutes `rm -rf` sobre carpetas si no estás 100% seguro de la ruta en la que estás parado (`pwd`).

#### 2. Espacios en nombres de carpetas
* **El error:** Escribir `cd Mis Documentos`. La terminal creerá que intentas entrar a dos carpetas distintas: `Mis` y `Documentos`.
* **La solución:** Usa comillas `cd "Mis Documentos"` o escapa el espacio con barra invertida `cd Mis\ Documentos/`.

#### 3. Error `command not found`
* **La causa:** Escribiste mal el comando (ej. `nod` en lugar de `node`) o el programa no está instalado en las variables de entorno del sistema (`PATH`).

#### 4. Permiso Denegado (*Permission Denied*)
* **La solución:** Nunca uses `sudo` por costumbre. Si una carpeta de tu proyecto da error de permisos, revisa que seas el dueño de la carpeta con `ls -l`.

## 🏠 Fase 5: Definición de Práctica en Casa / Reto Semanal

Demostrarás tu autonomía construyendo un proyecto completo sin tocar el ratón.

### 🏆 Proyecto Semanal: "El Reto del Explorador de Terminal"

**Descripción del Reto:**
Debes crear la estructura completa de un nuevo proyecto web utilizando **exclusivamente comandos de terminal**.

#### Pasos Obligatorios a Ejecutar:

1. **Crear el directorio raíz:**
   * Crea una carpeta llamada `proyecto-terminal-desde0/` dentro de tu directorio de proyectos y entra en ella.

2. **Crear la estructura de carpetas en un solo comando:**
   * Genera las carpetas `public/assets/images`, `public/assets/styles`, `src/controllers`, `src/routes` y `config`.

3. **Crear los archivos base:**
   * Crea `public/index.html`, `public/assets/styles/main.css`, `src/server.js` y `config/app.json`.

4. **Escribir contenido con comandos de terminal:**
   * Escribe el encabezado HTML básico dentro de `public/index.html` usando `echo` y redirección `>`.
   * Crea un archivo `README.md` en la raíz que contenga: *"# Proyecto Creado 100% desde la Terminal CLI"*.

5. **Verificación final:**
   * Ejecuta `ls -la` y `ls -R` (o `tree` si lo tienes instalado) y captura la salida visual de tu terminal.

6. **Limpieza del laboratorio previo:**
   * Sal de la carpeta con `cd ..` y elimina la carpeta `laboratorio-terminal` creada en clase usando `rm -r laboratorio-terminal`.
