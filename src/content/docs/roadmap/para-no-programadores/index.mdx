# Aprende a Programar sin Miedo y Construye tu Primer Software

> *"Cualquiera puede aprender a programar si se le explica con empatía, analogías cotidianas y proyectos que realmente tengan sentido."*

Bienvenido al curso **Programación Desde0 - Para no programadores**. Si nunca has escrito una sola línea de código, si las matemáticas te intimidaban en la escuela o si sientes que la tecnología avanza demasiado rápido, **este es tu punto de partida ideal**.

Aquí no asumimos que sabes nada de computación técnica. Te guiaremos paso a paso desde entender qué ocurre cuando abres una página web hasta publicar tu propia aplicación en internet.

---

## ¿Por qué esta ruta es diferente?

La mayoría de los cursos de programación fallan porque son abstractos, usan términos complicados sin explicarlos o saltan directamente a escribir sintaxis compleja sin enseñarte a razonar. En **Desde0** diseñamos una experiencia pensada para humanos:

<CardGrid stagger>
  <Card title="🧩 Cero Frustración" icon="smile">
    Comenzamos en la consola de tu navegador sin instalaciones pesadas ni terminales intimidantes en tus primeras semanas.
  </Card>
  <Card title="☕ Analogías del Mundo Real" icon="open-book">
    Cada concepto técnico se explica con ejemplos cotidianos (cajas etiquetadas, interruptores, máquinas de café y recetas).
  </Card>
  <Card title="🚀 Proyecto Real: ShortURL" icon="rocket">
    No harás ejercicios desconectados de calculadora: construirás un acortador de enlaces web Full-Stack real estilo Bitly.
  </Card>
  <Card title="🧠 Pensamiento Computacional" icon="laptop">
    Aprenderás a descomponer problemas complejos en pasos simples y lógicos que cualquier máquina puede resolver.
  </Card>
</CardGrid>

## El Proyecto Central: ShortURL

A lo largo del curso construirás de forma incremental **ShortURL**, una aplicación web completa que permite ingresar un enlace largo y transformarlo en una dirección corta funcional:

<CardGrid>
  <Card title="1. 🖥️ Frontend (Semana 6)" icon="laptop">
    **La cara visible:** Interfaz visual con HTML5 semántico, diseño elástico con CSS Flexbox y manipulación del DOM para captura y copiado al portapapeles.
  </Card>

  <Card title="2. ⚡ Backend (Semana 7)" icon="seti:nodejs">
    **El cerebro:** Servidor web en Node.js y Express con API REST, generación de códigos cortos y redirección HTTP 302 hacia el enlace original.
  </Card>

  <Card title="3. 🗄️ Base de Datos (Semana 8)" icon="seti:db">
    **La memoria:** Persistencia relacional segura con SQLite y sentencias SQL protegidas para almacenar las URLs de forma permanente.
  </Card>

  <Card title="4. ☁️ Control de Versiones y Nube (Semanas 9 a 12)" icon="rocket">
    **Puesta en producción:** Dominio de la terminal, repositorio en GitHub, variables de entorno (`.env`) y despliegue global en la nube con HTTPS gratuito.
  </Card>
</CardGrid>

## Ruta de Aprendizaje (24 Semanas / 12 Lecciones)

El programa se imparte en **24 semanas (12 lecciones exhaustivas, dedicando 2 semanas a cada lección)** organizadas en 4 grandes bloques formativos:

### 🟢 Bloque 1: Fundamentos y Mentalidad
1. [L1: Antes de empezar](/roadmap/para-no-programadores/1) <Badge text="Disponible" variant="success" />  
   *Derribar mitos, el funcionamiento de la web, la consola del navegador y tu primera instrucción.*
2. [L2: Conceptos básicos de programación](/roadmap/para-no-programadores/2) <Badge text="Disponible" variant="success" />  
   *Los 5 pilares de la lógica: variables, tipos de datos, operadores, condicionales y funciones.*

### 🟡 Bloque 2: Lenguaje, Paradigmas y Arquitectura
3. [L3: JavaScript Language Tour y Errores](/roadmap/para-no-programadores/3) <Badge text="Disponible" variant="success" />  
   *Manipulación de texto (Strings), arreglos funcionales (`map`, `filter`, `reduce`) y blindaje con `try...catch`.*
4. [L4: Paradigmas de Programación](/roadmap/para-no-programadores/4) <Badge text="Disponible" variant="success" />  
   *Programación Orientada a Objetos (`class`), funciones puras y asincronía moderna con `async / await`.*
5. [L5: Stacks Tecnológicos y Kickoff de ShortURL](/roadmap/para-no-programadores/5) <Badge text="Disponible" variant="success" />  
   *Qué es un Tech Stack, arquitectura Cliente-Servidor y prototipo en memoria del proyecto.*

### 🟠 Bloque 3: Construcción Full-Stack de ShortURL
6. [L6: Frontend: HTML, CSS y el DOM](/roadmap/para-no-programadores/6) <Badge text="Disponible" variant="success" />  
   *Estructura semántica, diseño responsivo y eventos interactivos en la pantalla.*
7. [L7: Backend: Servidores Web con Node.js y Express](/roadmap/para-no-programadores/7) <Badge text="Disponible" variant="success" />  
   *Protocolo HTTP, creación de API REST, enrutamiento dinámico y conexión con el cliente.*
8. [L8: Base de Datos: Persistencia con SQLite y SQL](/roadmap/para-no-programadores/8) <Badge text="Disponible" variant="success" />  
   *Diseño de tablas, consultas SQL (`CREATE`, `INSERT`, `SELECT`, `UPDATE`) y prevención de vulnerabilidades.*

### 🟣 Bloque 4: Herramientas Profesionales y Despliegue en la Nube
9. [L9: Uso de la Terminal y CLI](/roadmap/para-no-programadores/9) <Badge text="Disponible" variant="success" />  
   *Dominio de la línea de comandos POSIX, navegación rápida de carpetas y scripts de automatización.*
10. [L10: Control de Versiones con Git y GitHub](/roadmap/para-no-programadores/10) <Badge text="Disponible" variant="success" />  
    *Commits atómicos, ramas de trabajo, protección con `.gitignore` y publicación de tu repositorio.*
11. [L11: Sistemas Operativos y Variables de Entorno (.env)](/roadmap/para-no-programadores/11) <Badge text="Disponible" variant="success" />  
    *Gestión de procesos, configuración segura con `dotenv` y apagado limpio (*Graceful Shutdown*).*
12. [L12: DevOps, Despliegue en la Nube y Graduación](/roadmap/para-no-programadores/12) <Badge text="Disponible" variant="success" />  
    *Publicación global en la nube (PaaS) con dominio público HTTPS y celebración de graduación.*
