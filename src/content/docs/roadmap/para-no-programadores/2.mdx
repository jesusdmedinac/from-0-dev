## 🎯 Fase 2: Introducción Teórica y Objetivos (45 min)

En esta fase exploraremos los 5 pilares fundamentales de la programación mediante ejemplos prácticos en JavaScript.

### Objetivos de Aprendizaje de Hoy

1. **Variables (`let` y `const`):** Guardar y recuperar datos en la memoria de la computadora.
2. **Tipos de Datos:** Identificar texto (`string`), números (`number`), decisiones (`boolean`), listas (`array`) y objetos (`object`).
3. **Operadores:** Realizar cálculos matemáticos y comparaciones lógicas.
4. **Estructuras de Control:** Enseñar al programa a tomar decisiones (`if / else`) y a repetir tareas (`for / while`).
5. **Funciones:** Encapsular código en bloques reutilizables para no repetirnos.

---

### 1. Variables: Las cajas de la memoria

Imagina que la memoria de tu computadora es una habitación llena de estanterías vacías. Para guardar algo y encontrarlo después con facilidad, tomas una **caja**, le pegas una **etiqueta con un nombre** y colocas un **valor dentro**.

```javascript
/* 1 */ let /* 2 */ nombreUsuario /* 3 */ = /* 4 */ "Ada Lovelace";
```

* **`let` / `const`:** Avisa a JavaScript que reservamos memoria. Usamos `let` cuando el dato puede cambiar (ej. el nivel de un juego) y `const` cuando es un valor fijo e inmutable (ej. tu fecha de nacimiento).
* **Nombre de la variable:** Usamos la convención `camelCase` (ej. `precioProducto`, `estaAutenticado`).
* **`=` (Asignación):** Guarda el dato de la derecha en la variable de la izquierda.

---

### 2. Tipos de Datos Fundamentales

```javascript
// Texto (String): Siempre entre comillas
let ciudad = "Ciudad de México";

// Número (Number): Enteros o decimales, sin comillas
let temperatura = 23.5;

// Booleano (Boolean): Solo true (verdadero) o false (falso)
let esDiaSoleado = true;

// Lista (Array): Colección ordenada entre corchetes
let amigos = ["Carlos", "Diana", "Sebastián"];

// Objeto (Object): Ficha de datos estructurada entre llaves
let producto = {
  nombre: "Café de Especialidad",
  precio: 75,
  disponible: true
};
```

---

### 3. Operadores Esenciales

* **Aritméticos:** `+` (suma), `-` (resta), `*` (multiplicación), `/` (división), `%` (módulo o residuo).
* **Comparación:** `===` (¿es idéntico?), `!==` (¿es diferente?), `>` (mayor), `<` (menor), `>=` (mayor o igual).
* **Lógicos:** `&&` (AND: ambas condiciones deben ser verdaderas), `||` (OR: al menos una condición debe cumplirse), `!` (NOT: invierte el valor).

---

### 4. Estructuras de Control: Decisiones y Bucles

#### Decisiones (`if / else if / else`)
Permiten que el programa elija qué bloque de código ejecutar según una condición:

```javascript
let saldo = 120;
let costoProducto = 100;

if (saldo >= costoProducto) {
  console.log("¡Compra exitosa! Disfruta tu producto.");
} else {
  console.log("Saldo insuficiente. Por favor recarga fondos.");
}
```

#### Bucles (`for` y `while`)
Permiten repetir una acción automáticamente sin copiar y pegar código:

```javascript
// Repite exactamente 5 veces
for (let i = 1; i <= 5; i++) {
  console.log("Empaquetando caja número:", i);
}
```

---

### 5. Funciones: Máquinas de código reutilizable

Una función es como una cafetera: le introduces ingredientes (parámetros), ejecuta un proceso interno y te devuelve un resultado (`return`).

```javascript
function calcularTotal(precio, cantidad) {
  return precio * cantidad;
}

let totalCompra1 = calcularTotal(50, 3); // 150
let totalCompra2 = calcularTotal(12, 10); // 120
```

### 🧩 Reto 1: Calculadora de Cuentas y Propinas (20 min)

**Objetivo:** Dominar variables `let`/`const`, tipos numéricos y operaciones aritméticas.

Escribe y ejecuta en tu consola:

```javascript
// 1. Datos iniciales
const totalCuenta = 480; // Costo de la cena en el restaurante
const porcentajePropina = 0.15; // 15% de propina
const numeroPersonas = 4; // Amigos en la mesa

// 2. Cálculos
const montoPropina = totalCuenta * porcentajePropina;
const totalConPropina = totalCuenta + montoPropina;
const pagoPorPersona = totalConPropina / numeroPersonas;

// 3. Resultados en consola
console.log("Total de la comida: $" + totalCuenta);
console.log("Propina sugerida (15%): $" + montoPropina);
console.log("Total a pagar: $" + totalConPropina);
console.log("Cada persona paga: $" + pagoPorPersona);
```

---

### 🧩 Reto 2: El Portero Virtual / Control de Acceso (`if / else`) (25 min)

**Objetivo:** Practicar condicionales y operadores lógicos combinados (`&&`, `||`).

Vamos a simular el acceso a un evento exclusivo:

```javascript
let edad = 20;
let tieneBoletoVip = false;
let estaEnListaDeInvitados = true;

if (edad >= 18 && (tieneBoletoVip || estaEnListaDeInvitados)) {
  console.log("🟢 ¡Bienvenido al evento! Pasa a la zona preferencial.");
} else if (edad >= 18 && !tieneBoletoVip) {
  console.log("🟡 Eres mayor de edad pero necesitas adquirir tu boleto VIP en taquilla.");
} else {
  console.log("🔴 Acceso denegado: Evento exclusivo para mayores de 18 años.");
}
```

*Prueba cambiar los valores de `edad`, `tieneBoletoVip` y `estaEnListaDeInvitados` para observar cómo cambia el veredicto del programa.*

---

### 🧩 Reto 3: El Generador Automático de Tablas con Bucles (25 min)

**Objetivo:** Automatizar repeticiones con bucles `for` y `while`.

Generemos la tabla de multiplicar del número 7 en 3 líneas de código:

```javascript
let numeroTabla = 7;

console.log("--- Tabla del " + numeroTabla + " ---");
for (let multiplicador = 1; multiplicador <= 10; multiplicador++) {
  let resultado = numeroTabla * multiplicador;
  console.log(numeroTabla + " x " + multiplicador + " = " + resultado);
}
```

Ahora un contador regresivo de lanzamiento espacial con `while`:

```javascript
let cuentaAtras = 5;

while (cuentaAtras > 0) {
  console.log("T-menos " + cuentaAtras + " segundos...");
  cuentaAtras--; // Restamos 1 en cada vuelta
}

console.log("🚀 ¡Despegue exitoso!");
```

---

### 🧩 Reto 4: La Fábrica de Funciones Reutilizables (20 min)

**Objetivo:** Convertir nuestros retos anteriores en funciones modulares.

```javascript
// Función para verificar si un número es par o impar
function esPar(numero) {
  return numero % 2 === 0;
}

// Función para calcular el descuento de una tienda
function aplicarDescuento(precioOriginal, porcentajeDescuento) {
  let descuento = precioOriginal * (porcentajeDescuento / 100);
  return precioOriginal - descuento;
}

console.log("¿El número 24 es par?", esPar(24)); // true
console.log("¿El número 15 es par?", esPar(15)); // false
console.log("Precio final con 20% de descuento:", "$" + aplicarDescuento(500, 20)); // $400
```

## 🗣️ Fase 4: Exposición de Resultados, Debate y Debugging (45 min)

Compartimos pantallas, comparamos soluciones y analizamos las trampas clásicas del código en vivo.

### 🐞 Los Errores Típicos en Conceptos Básicos

#### 1. Confundir `=` (asignar) con `===` (comparar)
* **El error:** Escribir `if (edad = 18)` en lugar de `if (edad === 18)`.
* **Consecuencia:** `=` sobrescribe el valor de la variable en lugar de compararlo, provocando comportamientos inesperados.

#### 2. El Bucle Infinito en `while`
* **El error:** Olvidar la línea `contador++` o `cuentaAtras--` dentro del cuerpo de un `while`.
* **Consecuencia:** La condición nunca deja de ser verdadera y el navegador se congela.  
* *Tip de rescate:* Cierra la pestaña congelada con el administrador de tareas del navegador (`Shift + Esc` en Chrome).

#### 3. El Alcance de las Variables (*Scope*)
* **El error:** Declarar una variable dentro de un bloque `if { let secreto = 123; }` e intentar leerla fuera de las llaves.
* **Solución:** Las variables creadas con `let` dentro de `{ }` solo viven dentro de esas llaves.

## 🏠 Fase 5: Definición de Práctica en Casa / Reto Semanal (30 min)

Para consolidar tu aprendizaje antes de la siguiente clase, desarrollarás tu primer mini-sistema comercial.

### 🏆 Reto Semanal: "El Asistente de Caja del Supermercado"

**Descripción del Problema:**
Crea un programa en la consola que simule el cobro de una compra en un supermercado con las siguientes reglas:

1. Define un arreglo con los precios de 3 productos comprados: `let precios = [120, 45, 80];`
2. Utiliza un bucle `for` para sumar el precio de todos los productos y obtener el `subtotal`.
3. Crea una función llamada `calcularDescuento(monto)` que aplique las siguientes reglas con un `if/else`:
   - Si el subtotal es mayor a `$200`, aplica un **10% de descuento**.
   - Si el subtotal es menor o igual a `$200`, no aplica descuento (0%).
4. Calcula el total final a pagar.
5. Imprime en consola un ticket estructurado:
   ```
   ===============================
   🧾 TICKET DE COMPRA
   ===============================
   Subtotal: $245
   Descuento aplicado (10%): $24.50
   TOTAL A PAGAR: $220.50
   ===============================
   ```

<Aside type="tip" title="Criterio de evaluación para casa">
Prueba tu script cambiando los precios del arreglo: verifica que cuando la suma sea menor a $200 no se aplique descuento y que cuando supere $200 el descuento se calcule exactamente.
</Aside>
