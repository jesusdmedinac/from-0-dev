Desarrollar software nunca había sido tan accesible como hoy. Cada día contamos con más herramientas que eliminan las barreras técnicas para resolver problemas complejos. Gracias a la inteligencia artificial, muchas personas creen erróneamente que ya no es necesario aprender a programar; sin embargo, quienes estamos en la industria sabemos que la IA es un copiloto extraordinario, pero **requiere que tú seas el director de orquesta con una base sólida de fundamentos**.

Este taller está diseñado como una **experiencia formativa semanal estructurada en sesiones de 4 horas**, donde combinaremos teoría aplicada, programación en vivo, resolución de dudas y retos semanales.

## ☕ Fase 1: Rompehielos, Expectativas y Metodología (30 min)

Comenzamos la sesión conociéndonos, alineando metas y despejando cualquier duda inicial sobre la dinámica del taller.

### Tu Mentalidad de Inicio

Aprender a programar es exactamente como aprender a tocar un instrumento musical o un nuevo idioma. No se trata de memorizar sintaxis compleja, sino de **entrenar a tu mente para razonar en pasos lógicos**.

<Aside type="tip" title="Pregunta de reflexión para la sesión">
Antes de escribir una sola línea de código, reflexiona: **¿Por qué quieres aprender a programar?**  
¿Quieres crear una aplicación propia? ¿Buscas hacer una transición de carrera a la industria tecnológica? ¿Deseas automatizar tareas de tu trabajo actual? Tener claro tu objetivo será tu brújula en momentos desafiantes.
</Aside>

### Requisitos Técnicos

Para este taller no necesitas equipos costosos ni configuraciones complejas:
- **Computadora con cualquier sistema operativo:** Windows, macOS o Linux.
- **Navegador web moderno:** Google Chrome, Mozilla Firefox, Microsoft Edge, Safari o Brave (puedes consultar más detalles en este [artículo de referencia](https://jesusdmedinac.notion.site/C-mo-puedo-empezar-a-programar-2cac38be0050444cba099b1e3b21b029)).

## 🎯 Fase 2: Introducción al Tema y Objetivos (45 min)

En esta fase exploraremos qué es realmente el software y cómo las computadoras interpretan las instrucciones humanas.

### Objetivos de Aprendizaje de Hoy

Al finalizar esta sesión serás capaz de:
1. Entender qué hace un navegador web internamente cuando visita una página.
2. Abrir y navegar con soltura por las **Herramientas de Desarrollador (DevTools)**.
3. Utilizar la **Consola de JavaScript** para ejecutar comandos, operaciones y cuadros de diálogo interactivos.
4. Modificar elementos en vivo de una página web directamente con código.

### ¿Cómo funciona la Web a alto nivel?

Cuando navegas por internet, interactúas con dos mundos:
1. **El Cliente (Frontend):** Es tu navegador (Chrome, Safari). Su trabajo es recibir código (HTML, CSS, JavaScript) y pintarlo visualmente en tu pantalla.
2. **El Servidor (Backend):** Es una computadora remota donde viven las bases de datos y la lógica pesada.

<Aside type="note" title="Tu navegador ya es un entorno de desarrollo profesional">
No necesitas instalar programas pesados para empezar. Tu navegador ya incluye un **motor de JavaScript** completo (como el motor *V8* de Google Chrome) listo para interpretar y ejecutar código al instante.
</Aside>

## 💻 Fase 3: Práctica Semanal Asistida en Vivo (90 min)

¡Llegó el momento de poner las manos en el teclado! Realizaremos juntos 3 retos prácticos progresivos en la consola de tu navegador.

### Paso Previo: Abrir la Consola de Desarrollador

1. Haz **clic derecho** en cualquier parte vacía de esta página y selecciona **Inspeccionar** (*Inspect*).
2. En la ventana que se abre, localiza y haz clic en la pestaña **Consola** (*Console*).

<Aside type="tip" title="Atajos rápidos de teclado">
- **Windows / Linux:** Presiona `F12` o `Ctrl + Shift + J`.
- **macOS:** Presiona `Cmd + Option + J`.
</Aside>

### 🧩 Reto 1: La Consola como Panel de Control y Calculadora (25 min)

Vamos a familiarizarnos con el comando básico de salida: `console.log()`.

Escribe en la consola y presiona **Enter**:

```javascript
console.log("¡Hola Mundo! Estoy iniciando mi camino en Desde0.");
```

La función `console.log` le pide a la computadora que imprima un mensaje en el panel.

Ahora prueba realizar cálculos matemáticos directos:

```javascript
// Suma y resta
250 + 130 - 45

// Multiplicación y división (fíjate en los paréntesis para el orden)
(100 - 15) * 1.16

// ¿Cuántas horas tiene un año bisiesto?
366 * 24
```

---

### 🧩 Reto 2: Diálogos Interactivos con el Usuario (`alert` y `prompt`) (35 min)

Un programa se vuelve emocionante cuando interactúa con las personas. Vamos a crear un script que le pregunte su nombre al usuario y lo salude en una ventana emergente.

Escribe las siguientes líneas una por una en la consola:

```javascript
// 1. Mostramos una alerta de bienvenida
alert("¡Bienvenido al sistema interactivo!");

// 2. Pedimos un dato al usuario con prompt y lo guardamos
let nombreUsuario = prompt("¿Cuál es tu nombre?");

// 3. Respondemos utilizando el dato ingresado
alert("¡Mucho gusto, " + nombreUsuario + "! Tu primer programa interactivo está funcionando.");
```

#### Mini-Desafío en Vivo:
Crea una calculadora interactiva que pida dos números al usuario y muestre su suma total:

```javascript
let primerNumero = Number(prompt("Ingresa el primer número:"));
let segundoNumero = Number(prompt("Ingresa el segundo número:"));

let resultadoSuma = primerNumero + segundoNumero;
alert("El resultado de la suma es: " + resultadoSuma);
```

### 🧩 Reto 3: Hackeando en Vivo la Página Web (30 min)

JavaScript tiene el superpoder de modificar la página web en tiempo real a través del objeto `document`.

Prueba ejecutar estas instrucciones en la consola mientras observas esta misma pestaña:

```javascript
// 1. Cambia el título de la pestaña del navegador
document.title = "🚀 ¡Página personalizada por mí!";

// 2. Cambia el color de fondo de toda la pantalla
document.body.style.backgroundColor = "#F1F5F9";

// 3. Lanza un mensaje final de felicitación
console.log("¡Felicidades! Has interactuado directamente con el DOM de la página.");
```

*(Si recargas la página con F5, volverá a su estado original. ¡No puedes romper nada, así que experimenta con total libertad!)*

## 🗣️ Fase 4: Exposición de Resultados, Preguntas y Debugging (45 min)

En esta fase abrimos los micrófonos y la pantalla para revisar los resultados de la práctica, resolver dudas y aprender de los errores comunes.

### 🐞 Los Primeros Errores de Novato (y cómo solucionarlos)

Cuando programas, cometer errores es lo más normal del mundo. Los mensajes en rojo de la consola no son un regaño: **son pistas de la computadora para ayudarte**.

#### 1. `Uncaught SyntaxError: Invalid or unexpected token`
* **¿Por qué ocurre?** Olvidaste cerrar unas comillas (`"`) o un paréntesis `)`.
* **Ejemplo que falla:** `console.log("Hola Mundo);`
* **Solución:** Revisa que cada comilla y paréntesis que abras tenga su respectivo cierre.

#### 2. `Uncaught ReferenceError: [nombre] is not defined`
* **¿Por qué ocurre?** Escribiste mal el nombre de una función o variable. JavaScript distingue estrictamente entre mayúsculas y minúsculas (*case-sensitive*).
* **Ejemplo que falla:** `Console.log("Hola");` o `console.Log("Hola");`
* **Solución:** Escríbelo exactamente en minúsculas: `console.log(...)`.

#### 3. Sumas que se convierten en texto pegado (`"10" + "5" = "105"`)
* **¿Por qué ocurre?** Si no conviertes el texto de un `prompt()` con `Number()`, JavaScript asume que quieres pegar las letras en vez de sumar cantidades.

## 🏠 Fase 5: Definición de Práctica en Casa / Reto Semanal (30 min)

Para consolidar lo aprendido hoy antes de la siguiente sesión, realizarás tu primer proyecto en casa.

### 🏆 Reto Semanal: "El Calculador de Tiempo de Vida"

**Instrucciones:**
Abre la consola de tu navegador en cualquier página y crea un script interactivo que realice lo siguiente:
1. Muestre una alerta inicial: `"Bienvenido al calculador de edad"`.
2. Le pida al usuario su nombre con `prompt()`.
3. Le pida al usuario su año de nacimiento.
4. Calcule la edad aproximada del usuario (`2026 - añoNacimiento`).
5. Calcule aproximadamente cuántos meses y días ha vivido (`edad * 12` meses, `edad * 365` días).
6. Muestre el resultado en un mensaje de alerta final:  
   *`"Hola [Nombre], tienes aproximadamente [X] años, lo que equivale a [Y] meses o [Z] días de vida. ¡Increíble!"`*

<Aside type="tip" title="Criterio de éxito para casa">
Pruébalo con familiares o amigos ingresando diferentes años de nacimiento y verifica que los cálculos matemáticos se muestren correctamente en la ventana de alerta.
</Aside>
